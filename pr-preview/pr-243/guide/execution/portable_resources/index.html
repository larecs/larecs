      Use portable resources

      Use portable resources

      Read an owning sample collection through the same particle kernel on host and device. Start with shared resources and device selection. Adapter-backed device execution and mutable adapters follow the experimental status. This stage uses read-only views; kernel outputs remain per-entity components.

      Separate the owner from the kernel view

      The particle fields stay plain; time remains an ordinary read resource.

      @fieldwise_init
struct Position(Copyable, Movable, TrivialRegisterPassable):
    """Particle coordinates, using device-compatible scalar arithmetic."""

    var x: Float32
    var y: Float32


@fieldwise_init
struct Velocity(Copyable, Movable, TrivialRegisterPassable):
    """Particle displacement per unit of simulated time."""

    var dx: Float32
    var dy: Float32


@fieldwise_init
struct Time(Copyable, Movable):
    """Shared simulated step length."""

    var delta: Float32

      These types have no heap ownership. The new resource sources below instead own collections and expose a different representation inside kernels.

      Use BufferResource for a contiguous scalar buffer. Add a custom DevicePassableResource only when the kernel needs a domain-specific view, such as the last sample of a rectangular grid.

      comptime Samples = BufferResource[DType.float32]


@fieldwise_init
struct Grid(DevicePassableResource):
    """Owns samples and dimensions on the host."""

    comptime Adapter = GridAdapter
    var values: List[Float32]
    var width: Int
    var height: Int


@fieldwise_init
struct GridView(TrivialRegisterPassable):
    """Borrows immutable samples in the current target's address space."""

    var values: Pointer[Float32, ImmUntrackedOrigin]
    var width: Int
    var height: Int

    def last(self) -> Float32:
        """Reads the final sample of a validated nonempty grid.

        Returns:
            The bottom-right sample.
        """
        return self.values[unsafe_offset=self.width * self.height - 1]

      Samples owns its host collection and supplies the built-in immutable ReadBuffer with length and bounds-checked indexing. Do not index an empty buffer. Grid owns its List; GridView borrows samples through a pointer and exposes last(). Its dimensions must describe a nonempty grid. The pointer in a view is target-local: it refers to host memory during a host run and device memory during a device run.

      Implement validation and target preparation

      The stateless ResourceAdapter checks the current owner and prepares the same descriptor type for each target.

      struct GridAdapter(ResourceAdapter):
    """Prepares the same immutable descriptor for either target."""

    comptime Source = Grid
    comptime View[mut: Bool] = GridView

    @staticmethod
    def validate(source: Self.Source) raises:
        """Validates shape and bounds before either target is prepared.

        Args:
            source: Current host owner.

        Raises:
            Error: If shape arithmetic overflows or sample counts disagree.
        """
        if source.width <= 0 or source.height <= 0:
            raise Error("Grid dimensions must be positive")
        if source.width > Int(Int64.MAX) // source.height:
            raise Error("Grid dimensions overflow")
        if source.width * source.height != len(source.values):
            raise Error("Grid shape must match sample count")

    @staticmethod
    def bind_host(source: Self.Source) raises -> Self.View[False]:
        """Borrows the validated owner's samples without copying.

        Args:
            source: Owner retained through invocation completion.

        Returns:
            Host-local immutable descriptor.
        """
        return {
            Pointer[Float32, ImmUntrackedOrigin](
                unsafe_from_address=Int(source.values.unsafe_ptr())
            ),
            source.width,
            source.height,
        }

    @staticmethod
    def prepare_device(
        source: Self.Source, mut cache: ResourceDeviceCache
    ) raises -> Self.View[False]:
        """Uploads samples through invocation-owned staging.

        Args:
            source: Current validated owner.
            cache: Source-type and device-context local allocations.

        Raises:
            Error: If allocation or upload fails.

        Returns:
            Descriptor containing a device-local sample pointer.
        """
        return {
            cache.upload[Float32](0, Span(source.values)),
            source.width,
            source.height,
        }

      validate rejects zero dimensions, overflow, and inconsistent counts before binding either target, including empty entity matches. bind_host points into the retained source, never a temporary list. Its untracked origin makes the owner/lifetime obligations explicit; it does not transfer ownership.

      prepare_device uses ResourceDeviceCache slot 0 for samples. cache.upload snapshots supported pointer-free trivial samples in owned staging before enqueueing. Larecs uploads the descriptor separately, using reserved slot -1. Give additional arrays distinct nonnegative stable slots; do not enqueue copies from external host pointers or temporary allocations. The cache belongs to the source type, world, and device context. It retains allocation capacity; by default preparation still uploads current data each run. Copy reuse can skip read-view preparation when revisions match.

      Request the source type and receive its view

      Both Resources and the getter name the owning source type.

      comptime move_filter = Filter().include[Position]().read[Velocity]()
comptime move_resources = Resources().read[Time, Samples, Grid]()


def move(context: KernelContext[move_filter, move_resources]):
    """Uses source-type lookup to read two portable views.

    Args:
        context: Particle rows, plain time, and adapted resources.
    """
    ref samples = context.resources.get[Samples]()
    ref grid = context.resources.get[Grid]()
    ref time = context.resources.get[Time]()
    var scale = samples[0] + grid.last()
    for particle in context:
        ref position = particle.get[Position]()
        ref velocity = particle.get[Velocity]()
        position.x += velocity.dx * time.delta * scale
        position.y += velocity.dy * time.delta * scale

      Inside move, get[Samples]() returns ReadBuffer and get[Grid]() returns GridView, both immutable. Outside execution, world.resources.get[Grid]() returns the owning Grid. Lookup uses source identity, so two owners may share a view type without becoming the same resource. Adapters register automatically when the source is added or inserted with set; there is no adapter factory.

      The driver adds both sources, changes the grid owner between runs, and checks validation without matching entities.

      @fieldwise_init
struct Move[backend: ExecutionBackend](System):
    """Runs movement with access-selected resource views."""

    def update(mut self, mut context: SystemContext[...]) raises:
        """Binds resources for one complete invocation.

        Args:
            context: Access to the particle world.

        Raises:
            Error: If validation, preparation, or execution fails.
        """
        context.run[move, backend=Self.backend]()


def run_stage[backend: ExecutionBackend]() raises:
    """Checks owner edits, portable reads, and invalid shape rejection.

    Parameters:
        backend: Target to validate independently.

    Raises:
        Error: If execution or an assertion fails.
    """
    var world = World[Position, Velocity]()
    world.resources.add(
        Time(0.25),
        Samples([Float32(1)]),
        Grid([Float32(0), Float32(0), Float32(0), Float32(2)], 2, 2),
    )
    var walker = world.storage.add_entity(Position(0, 0), Velocity(1, 2))
    var scheduler = Scheduler[Position, Velocity](world^)
    scheduler.add_system(Move[backend]())
    scheduler.initialize()
    scheduler.update(steps=1)
    assert_almost_equal(scheduler.world.storage.read[Position](walker).x, 0.75)
    scheduler.world.resources.get[Grid]().values[3] = 3
    scheduler.update(steps=1)
    assert_almost_equal(scheduler.world.storage.read[Position](walker).x, 1.75)
    assert_almost_equal(scheduler.world.storage.read[Position](walker).y, 3.5)
    assert_equal(scheduler.world.resources.read[Grid]().values[3], 3)
    scheduler.finalize()

    # Adapter validation also runs when no entities match.
    var empty = World[Position, Velocity]()
    empty.resources.add(
        Time(0.25), Samples([Float32(1)]), Grid(List[Float32](), 2, 2)
    )
    var context = SystemContext(empty)
    with assert_raises():
        context.run[move, backend=backend]()


def main() raises:
    """Labels executed resource targets separately from hardware skips.

    Raises:
        Error: If an executed target fails.
    """
    run_stage[ExecutionBackend.HOST]()
    print("PASS: host buffer/grid views, owner edits, and empty validation")
    comptime if has_accelerator():
        run_stage[ExecutionBackend.DEVICE]()
        print("PASS: actual device buffer/grid views and particle checks")
    else:
        print("SKIP: device resources (no accelerator compilation support)")

      The first step uses scale 1 + 2 and ends at x=0.75; the edited owner changes the next scale to 1 + 3 and ends at (1.75, 3.5). Each target runs a fresh simulation. The device PASS line confirms actual sample transfer and execution; the SKIP line means only host validation ran. From the repository root, execute pixi run mojo run -I src examples/particles/portable_resources.mojo.

      Keep sources and views valid until completion

      Larecs validates sources, leases them, and retains descriptors until synchronous completion, including the join of threaded host workers. Reentrant lookup, replacement, or removal of a bound source raises. Copying/moving/destroying leased storage through an escaped alias aborts. Neither a view, its pointers, nor references obtained from it may escape the invocation.

      Every read view and all reachable storage must support concurrent reads without hidden mutation. Escaped aliases must not mutate, resize, relocate, or free the backing collection while a run uses it. An immutable pointer field alone does not establish that contract. Read adapters bind once on the coordinating host caller for threaded execution, then share the retained descriptor until join.

      Use a writer view only when the adapter supports it

      This GridAdapter is read-only. Resources[Grid]() means read-write and is rejected; declare read explicitly. For shared output, first consider per-row results and a later reduction.

      Current mutable adapters can opt into supports_mutation for sequential host writes and additionally supports_concurrent_mutation for threaded/device writes. These capabilities are author guarantees: an exclusive source lease does not prevent races among workers of one invocation. write selects fresh, adapter-initialized output; read_write preserves it. The descriptor remains immutable; its methods control backing writes. Preparation and finalization run once per invocation, even for empty matches, and mutable adapters prepare on every call despite copy reuse. The adapter reference and checked scatter example cover the hooks and atomic slot-reservation pattern.

      Troubleshooting

      Failure or restriction Fix
      Grid validation error Match dimensions and sample count before running. Empty entity matches do not bypass validation.
      Mutable declaration rejected Use explicit read for these sources, or implement the writer protocol and required capabilities. Ordinary device write-only resources remain unsupported.
      Invalid or stale view pointer Return target-local, owner/cache-backed memory; keep aliases from invalidating it. Do not byte-transfer a host pointer as an ordinary resource or capture.
      Unexpected stale samples with reuse enabled Reacquire the owner through get after each run, or explicitly invalidate after an escaped-reference write.
      Adapter finalizer raises Published outputs remain; the invocation is not a transaction. See device failure behavior.
