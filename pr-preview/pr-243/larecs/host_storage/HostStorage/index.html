      HostStorage

      @memory_only
struct HostStorage[*ComponentTypes: ComponentType]

      Holds all the component and entity data for a world.

      This is always used in combination with a World instance, e.g. as a member of it.

      Access it through world.storage, for example var entity = world.storage.add_entity(Position(10.0, 20.0)). Entities, components and the world shows a complete program.

      Aliases

      component_manager

      The component manager assigning IDs to ComponentTypes.

      component_manager = ComponentManager[ComponentTypes]

      Iterator

      Locked storage range type for queries and low-level batch results.

      Iterator[archetype_mutability: Bool, //, archetype_origin: Origin[mut=archetype_mutability], lock_origin: MutOrigin, *, row_filter: Filter[_include, _exclude, _is_exclusive, _read, _written] = Filter(), has_ranges: Bool = False]: AnyStruct[LockedEntityRange[archetype_origin, lock_origin, ComponentTypes, row_filter=row_filter, has_ranges=has_ranges]] = LockedEntityRange[archetype_origin, lock_origin, ComponentTypes, row_filter=row_filter, has_ranges=has_ranges]

      These iterators are copyable. Each copy preserves its source’s current traversal position and acquires a distinct structural-change lock that is released independently. Copying aborts if no lock is available; moving an iterator transfers its existing lock without acquiring another one.

      query

      Returns a locked, read-only iterator over all Entities matching the filter.

      def query[filter: Filter](mut self, out iterator: LockedEntityRange[origin_of(self._archetypes), origin_of(self._locks), ComponentTypes, row_filter=iterator.filter])
      Exact declaration 
      def query[filter: Filter[iterator.filter._include, iterator.filter._exclude, iterator.filter._is_exclusive, iterator.filter._read, iterator.filter._written]](mut self, out iterator: LockedEntityRange[origin_of(self._archetypes), origin_of(self._locks), ComponentTypes, row_filter=iterator.filter])

      The lock is acquired immediately and held for the iterator’s lifetime, preventing structural changes to the world until it is dropped. The iterator can be copied; every copy preserves the current traversal position and acquires a distinct lock that is released independently. Copying aborts if no lock is available. Component values are read-only through this iterator; mutate components from inside a system instead, via SystemContext.run.

      The yielded ArchetypeRowAccessor’s get[T]() is checked at compile time against filter: T must be included by filter (via Filter.include), since only then is every matching archetype guaranteed to carry it. Use unsafe_get[T]() for a component filter doesn’t guarantee, or has[T]() to check first.

      Parameters:

      • filter (Filter[iterator.filter._include, iterator.filter._exclude, iterator.filter._is_exclusive, iterator.filter._read, iterator.filter._written]): The compile-time Filter specifying which components to include or exclude.

      Args:

      • self (Self)
      • iterator (LockedEntityRange[origin_of(self._archetypes), origin_of(self._locks), ComponentTypes, row_filter=iterator.filter])

      Returns:

      LockedEntityRange[origin_of(self._archetypes), origin_of(self._locks), ComponentTypes, row_filter=iterator.filter]: A copyable, locked iterator over all entities matching the filter, with read-only component access. Each copy owns a distinct lock.

      Raises:

      LarecsError: If no lock is available.

      add_entity

      Returns a new or recycled Entity.

      def add_entity[*Ts: ComponentType](mut self, var *components: *Ts.values) -> Entity

      The given component types are added to the entity. Do not use during HostStorage.query iteration!

      ⚠️ Important: Entities are intended to be stored and passed around via copy, not via pointers! See Entity.

      Example:

      @fieldwise_init
struct Position(Copyable, Movable):
    var x: Float64
    var y: Float64

@fieldwise_init
struct Velocity(Copyable, Movable):
    var dx: Float64
    var dy: Float64

def main() raises:
    var world = World[Position, Velocity]()
    var entity = world.storage.add_entity(
        Position(0, 0),
        Velocity(0.5, -0.5),
    )
    assert_true(world.storage.has[Velocity](entity))

      add_entities

      Adds a batch of Entities.

      def add_entities[*Ts: ComponentType](mut self, *components: *Ts.values, *, count: Int, out iterator: LockedEntityRange[origin_of(self._archetypes), origin_of(self._locks), ComponentTypes, has_ranges=True])

      The given component types are added to the entities. Do not use during HostStorage.query iteration!

      Example:

      @fieldwise_init
struct Position(Copyable, Movable):
    var x: Float64
    var y: Float64

@fieldwise_init
struct Velocity(Copyable, Movable):
    var dx: Float64
    var dy: Float64

def main() raises:
    var world = World[Position, Velocity]()
    var x = 0.0
    for entity in world.storage.add_entities(
        Position(0, 0),
        Velocity(0.5, -0.5),
        count=5,
    ):
        # Initialize each new entity while the range is locked.
        entity.unsafe_get[Position]().x = x
        x += 1.0
    assert_equal(len(world), 5)
