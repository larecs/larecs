          mut_capture

          Development reference · Larecs 1.0.0b1 · revision 24a607075a78. Host threading and device execution are experimental. Compatibility and status.

          Mojo functionSource

          mut_capture

          Expand all   Collapse all

          Binds a host-local value for kernel mutation and device copy-back.

          def mut_capture[T: Copyable, origin: MutOrigin](ref[origin] value: T) -> CaptureBinding[T, origin]

          Parameters:

          • T (Copyable): The captured value type.
          • origin (MutOrigin): The inferred borrow origin of the host-local value.

          Args:

          • value (T): The value to borrow, upload, and overwrite after device execution.

          Returns:

          CaptureBinding[T, origin]: A mutable binding borrowing value.
