      DeviceComponentStorage

      @memory_only
struct DeviceComponentStorage[*ComponentTypes: ComponentType]

      Owns one byte-addressed device column per configured component type.

      Each initialized column has an independent valid row count. Its buffer length is a byte capacity, at least the row count times the component size. Capacity and valid row counts never shrink; smaller uploads overwrite only their range and retain previously valid suffix rows.

      Aliases

      • component_manager = ComponentManager[ComponentTypes]: The component manager assigning IDs to ComponentTypes.
      • Columns = Array[Optional[DeviceBuffer[DType.uint8]], len[TypeList[values]](ComponentTypes)]: The type of the per-component device column array.

      Parameters

      • *ComponentTypes (ComponentType): The component types managed by this storage.

      Implemented traits

      AnyType, Copyable, Deinitable, Movable

      ensure_column

      Ensures the device column for T exists and covers length rows.

      def ensure_column[T: ComponentType](mut self, length: Int)

      Creates or grows the column as needed, but uploads no data into it. Marks at least length rows valid for kernel output; the caller must write newly exposed rows before downloading them. Existing valid rows and capacity are retained when length is smaller. Used for a kernel component that is write-only for the current call: the column must exist before the kernel writes through it, but nothing needs uploading first, since a write-only component’s prior value is never read by the kernel.

      Parameters:

      • T (ComponentType): The component type of the column to ensure.

      Args:

      • self (Self)
      • length (Int): The minimum number of rows the column must cover.

      Raises:

      Error: If length is negative or device allocation fails.

      reserve_column

      Reserves device capacity without publishing unwritten logical rows.

      def reserve_column[T: ComponentType](mut self, length: Int)

      Existing valid rows survive growth. A new column allocates at least the initial capacity or requested rows; subsequent growth doubles byte capacity unless the request is larger. Smaller requests retain both capacity and valid length. Use ensure_column instead when promising output rows that a kernel will write.

      Parameters:

      • T (ComponentType): The component type whose capacity to reserve.

      Args:

      • self (Self)
      • length (Int): The minimum row capacity, which must be nonnegative.

      Raises:

      Error: If length is negative or device allocation or copying fails.

      Parameters:

      Args:

      • data (Span[T, origin]): The host data to upload.
