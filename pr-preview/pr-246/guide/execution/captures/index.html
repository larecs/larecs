      Pass local values to kernels

      Pass local values to kernels

      Give the particle kernel a step-local scale and get a particle count back, without storing either value as a world resource. Use a lexical closure when the kernel runs sequentially on the host, and explicit capture slots when the same kernel must also run on a device. Threaded execution accepts neither; pass its inputs through read-only resources or components.

      Start with Execute on a device, which introduces the backend parameter. Run threaded host kernels defines thin kernels.

      Borrow locals with a closure on the host

      Both programs on this page use the portable particle model.

      A lexical closure is a def nested inside another function that names the local variables it uses in a capture list. Here, move is defined inside Move.update and passed to run as a value:

      @fieldwise_init
struct Move(System):
    """Counts particles through a sequential host closure."""

    def update(mut self, mut context: SystemContext[...]) raises:
        """Moves the particles and observes a synchronous captured result.

        Args:
            context: Access to the particle world.

        Raises:
            Error: If resources, execution, or the visit check fail.
        """
        var scale: Float32 = 2
        var visits = 0

        def move(
            rows: KernelContext[
                Filter().include[Position]().read[Velocity](),
                Resources().read[Time](),
            ]
        ) {imm scale, mut visits}:
            """Moves each row and counts it through a host borrow.

            Args:
                rows: One matching physical store's rows and time.
            """
            ref time = rows.resources.get[Time]()
            for particle in rows:
                ref position = particle.get[Position]()
                ref velocity = particle.get[Velocity]()
                position.x += velocity.dx * time.delta * scale
                position.y += velocity.dy * time.delta * scale
                visits += 1

        context.run(move)
        assert_equal(visits, 2)

      The capture list {imm scale, mut visits} borrows scale read-only and visits mutably. context.run(move) selects the overload that takes a callable value; it runs only sequentially on the host. Larecs calls move once per matching physical store, and visits increases once per row. run returns after the last call, so the assertion sees the final count.

      The driver puts the two particles into different physical stores:

      def main() raises:
    """Checks the closure across two matching physical stores.

    Raises:
        Error: If setup, execution, or a position check fails.
    """
    var world = World[Position, Velocity, Int32]()
    world.resources.add(Time(0.25))
    var walker = world.storage.add_entity(Position(0, 0), Velocity(1, 0))
    var climber = world.storage.add_entity(
        Position(5, 0), Velocity(0, 2), Int32(1)
    )
    var scheduler = Scheduler[Position, Velocity, Int32](world^)
    scheduler.add_system(Move())
    scheduler.run(steps=1)
    assert_almost_equal(scheduler.world.storage.read[Position](walker).x, 0.5)
    assert_almost_equal(scheduler.world.storage.read[Position](climber).y, 1.0)
    print("PASS: lexical host captures across two stores")

      The extra Int32 component gives climber a different composition and therefore its own physical store; it does not change which entities move matches. Both particles move once, and visits counts rows across both calls.

      From the repository root, run:

      pixi run mojo run -I src examples/particles/lexical_closure.mojo

      Declare explicit slots for a thin kernel

      A thin kernel cannot borrow locals, but it can declare ordered capture slots with Captures. The system binds a local value to each slot when it calls run, on the host or on a device.

      comptime move_filter = Filter().include[Position]().read[Velocity]()
comptime move_resources = Resources().read[Time]()
comptime locals_spec = Captures[ReadCapture[Float32], MutCapture[Int32]]()


def move(context: KernelContext[move_filter, move_resources, locals_spec]):
    """Moves particles and records the processed count with a single writer.

    Args:
        context: Rows, time, and ordered scale/count capture slots.
    """
    ref time = context.resources.get[Time]()
    var scale = context.captures.get[0]()
    for particle in context:
        ref position = particle.get[Position]()
        ref velocity = particle.get[Velocity]()
        position.x += velocity.dx * time.delta * scale
        position.y += velocity.dy * time.delta * scale
    # The count is shared, not one private scalar per device thread.
    comptime if is_gpu():
        if global_idx.x != 0:
            return
    context.captures.get[1]() += context.length

      Slot 0 is a ReadCapture input; get[0]() returns its value. Slot 1 is a MutCapture output. Every invocation, and on a device every thread, sees the same output value, so only one writer may update it:

      • On the host, each invocation covers one physical store and adds its own row count, context.length. Sequential invocations never overlap.
      • On a device, one launch covers all rows. comptime if is_gpu() compiles the check only for the device, where only the thread with global index zero adds the packed row count.

      This works because no thread reads another thread’s result. A thread-zero branch is not a barrier, and it does not make a general reduction safe.

      Bind locals in the declared order when the system runs:

      @fieldwise_init
struct Move[backend: ExecutionBackend](System):
    """Binds local values for one synchronous step."""

    def update(mut self, mut context: SystemContext[...]) raises:
        """Checks count copy-back before the system returns.

        Args:
            context: Access to the simulation world.

        Raises:
            Error: If binding, execution, or the count check fails.
        """
        var scale: Float32 = 2
        var processed: Int32 = 0
        context.run[move, backend=Self.backend](
            read_capture(scale), mut_capture(processed)
        )
        assert_equal(scale, 2)
        assert_equal(processed, 37)

      read_capture and mut_capture borrow scale and processed until run returns. On the host, the kernel uses the original values. On a device, Larecs uploads every binding on each call and copies the mutable slot back before run returns, so processed holds 37 at the assertion.

      From the repository root, run:

      pixi run mojo run -I src examples/particles/captures.mojo

      A PASS line for the device means the slots were bound, executed, and copied back on the accelerator; a SKIP line means only the host ran.

      Variations

      Keep a value between steps

      A capture lives for one run call. A value that persists between steps, or that owns memory, belongs in a resource or a portable resource.

      Produce one result per particle

      When many invocations or threads contribute to a result, write a per-particle component and reduce it after run, as in Coordinate shared writes.

      Failures and limits

      Failure Cause and fix
      Compile error on the slot count, type, or mutability Bind one value per slot in declaration order, with the declared type. Two slots may share a type; their index distinguishes them.
      Borrow-checker error on one local One local cannot be bound read-only and mutably in the same call. Use separate values.
      Compile error for a device capture that owns memory or holds a pointer Device captures copy plain bytes. Use a portable resource for owning data.
      Wrong result from several writers A mutable slot provides no synchronization. Use one writer, or per-particle output.
      Compile error for a closure with DEVICE or threaded=True Lexical closures run only sequentially on the host. Use explicit slots for a device.

      Keep references from capture slots and closure borrows inside the kernel; they must not outlive the call. The capture reference lists the remaining binding rules.

@fieldwise_init
struct Move[backend: ExecutionBackend](System):
    """Binds local values for one synchronous step."""

    def update(mut self, mut context: SystemContext[...]) raises:
        """Checks count copy-back before the system returns.

        Args:
            context: Access to the simulation world.

        Raises:
            Error: If binding, execution, or the count check fails.
        """
        var scale: Float32 = 2
        var processed: Int32 = 0
        context.run[move, backend=Self.backend](
            read_capture(scale), mut_capture(processed)
        )
        assert_equal(scale, 2)
        assert_equal(processed, 37)


def run_stage[backend: ExecutionBackend]() raises:
    """Checks empty bindings, two physical stores, and a partial device block.

    Parameters:
        backend: Target to validate.

    Raises:
        Error: If setup, execution, or an assertion fails.
    """
    var world = World[Position, Velocity, Int32]()
    world.resources.add(Time(0.25))
    var scale: Float32 = 2
    var processed: Int32 = 9
    var empty_context = SystemContext(world)
    empty_context.run[move, backend=backend](
        read_capture(scale), mut_capture(processed)
    )
    assert_equal(processed, 9)
    _ = world.storage.add_entities(Position(0, 0), Velocity(1, 2), count=18)
    _ = world.storage.add_entities(
        Position(0, 0), Velocity(1, 2), Int32(1), count=19
    )
    var scheduler = Scheduler[Position, Velocity, Int32](world^)
    scheduler.add_system(Move[backend]())
    scheduler.run(steps=1)
    for particle in scheduler.world.storage.query[move_filter]():
        assert_almost_equal(particle.get[Position]().x, 0.5)
        assert_almost_equal(particle.get[Position]().y, 1.0)


def main() raises:
    """Always executes host checks and labels accelerator coverage explicitly.

    Raises:
        Error: If any executed target fails.
    """
    run_stage[ExecutionBackend.HOST]()
    print("PASS: explicit host captures, including empty matches")
    comptime if has_accelerator():
        run_stage[ExecutionBackend.DEVICE]()
        print("PASS: actual device captures and synchronous count copy-back")
    else:
        print("SKIP: device captures (no accelerator compilation support)")
