      Archetype represents an ECS archetype.

      reserve

      Extends the capacity of the archetype by factor 2 using power-of-2 allocation strategy.

      def reserve(mut self)

      Doubles the current capacity (minimum 8) to provide exponential growth that minimizes the frequency of memory reallocations while maintaining reasonable memory usage. This follows standard container growth patterns optimized for amortized performance.

      Args:

      • self (Self)

      Extends the capacity of the archetype to at least the specified number of entities.

      def reserve(mut self, new_capacity: Int)

      Uses a power-of-2 allocation strategy to ensure optimal memory alignment and reduce fragmentation. The actual allocated capacity will be the next power of 2 greater than or equal to the requested capacity.

      Does nothing if the requested capacity is not larger than the current capacity, avoiding unnecessary work and maintaining existing memory layout.

      Example:

      # Requesting 100 entities will allocate capacity for 128 (next power of 2)
archetype.reserve(100)  # Actually reserves 128

# Requesting 64 entities allocates exactly 64 (already power of 2)
archetype.reserve(64)   # Actually reserves 64

      Args:

      • self (Self)
      • new_capacity (Int): The minimum required capacity. The actual allocated capacity will be next_power_of_two(new_capacity) to maintain power-of-2 growth.

      set_component_range

      Overwrites the component with the given Type T for multiple consecutive, already-initialized entities starting with the given index.

      def set_component_range[T: ComponentType](mut self, start_entity_idx: Int, count: Int, value: T)

      Caution: This destroys the existing value at each target row before writing the new one, so every row in [start_entity_idx, start_entity_idx + count) must already hold a valid, initialized T value. Use Archetype.init_component_range instead for rows that were just appended or migrated and have not been initialized for T yet.

      Parameters:

      • T (ComponentType): The type of the component. Constraints: Must be contained in the component manager.

      Args:

      • self (Self)
      • start_entity_idx (Int): The index of the first entity to set.
      • count (Int): The number of elements to set.
      • value (T): The value to fill the component with.

      Raises:

      LarecsError: If the component is not present.

      init_component_range

      Initializes the component with the given Type T for multiple consecutive, uninitialized entities starting with the given index.

      def init_component_range[T: ComponentType](mut self, start_entity_idx: Int, count: Int, value: T)

      Unlike Archetype.set_component_range, this does not destroy any prior value at the target rows: it places a fresh copy of value directly into each row. Use this for rows that were just appended (e.g. via Archetype.extend) or migrated (e.g. via Archetype.unsafe_move_all_from_archetype) and therefore hold uninitialized memory for T.

      Parameters:

      • T (ComponentType): The type of the component. Constraints: Must be contained in the component manager.

      Args:

      • self (Self)
      • start_entity_idx (Int): The index of the first uninitialized entity row.
      • count (Int): The number of elements to initialize.
      • value (T): The value to fill the component with.

      Raises:

      LarecsError: If the component is not present.

      unsafe_move_all_from_archetype

      Moves all entities and shared components from another archetype.

      def unsafe_move_all_from_archetype[source_origin: MutOrigin](mut self, source: Pointer[Self, source_origin], excluded_components: _BitMask[Int(256)] = _BitMask()) -> Int

      This helper is intended for internal batch migration paths where the caller has already proven that source and destination archetypes are distinct, but Mojo’s alias analysis cannot express that relationship. Components absent from the destination or excluded from moving are destroyed in the source.

      Parameters:

      • source_origin (MutOrigin): The origin of the source archetype.

      Args:

      • self (Self)
      • source (Pointer[Self, source_origin]): An unsafe pointer to the source archetype. Must not point to self!
      • excluded_components (_BitMask[Int(256)]): Components to destroy instead of moving.

      Returns:

      Int: The index of the first newly appended entity.

      Constraints:

      The source and destination archetypes must be distinct.
