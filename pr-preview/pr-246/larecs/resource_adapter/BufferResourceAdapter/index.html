BufferResourceAdapter

Source

Stateless adapter for a contiguous scalar BufferResource.

Traits

AnyType, Deinitable, Movable, ResourceAdapter

Parameters

  • dtype: DType — Scalar sample datatype.

Source

Section titled “Source”

Owning host buffer type.

View

Section titled “View”

Read-only sample view; mutable resource declarations are rejected.

Parameters

  • mut: Bool — Requested access mode; this adapter supports only read access.

supports_mutation

Section titled “supports_mutation”

Whether write and read_write declarations are supported.

supports_concurrent_mutation

Section titled “supports_concurrent_mutation”

Whether mutable views are safe for concurrent GPU or threaded host use.

validate

Section titled “validate”

Source

Validates scalar storage before preparation.

Arguments

  • source: BufferResource[dtype] — Current host sample owner.

Raises

Error: If the byte count overflows the supported address range.

bind_host

Section titled “bind_host”

Source

Builds an immutable descriptor borrowing host samples.

Arguments

  • source: BufferResource[dtype] — Validated host sample owner.

Returns

Portable view over host samples.

Raises

Error: If descriptor construction fails.

prepare_device

Section titled “prepare_device”

Source

Uploads the current samples and constructs a device descriptor.

Arguments

  • source: BufferResource[dtype] — Validated host sample owner.
  • cache: ResourceDeviceCache — Context-local exclusively leased cache.

Returns

Portable view over device samples.

Raises

Error: If allocation or upload fails.
