test_copy_move_del

Source

Test the copy, move, and delete operations of a container.

The tracked value uses MutUntrackedOrigin for its counters intentionally. This keeps the produced container type fixed across call sites. The purpose of this helper is to verify lifecycle behavior, not caller-origin propagation.

Parameters

  • Container: Copyable & Deinitable — The type of the container to test.
  • container_factory: def(var val: MemTestStruct[MutUnsafeAnyOrigin, MutUnsafeAnyOrigin, MutUnsafeAnyOrigin]) thin -> Container — A function that creates a container from a MemTestStruct.

Arguments

  • init_moves: Int — The expected number of element move operations during initialization.
  • copy_moves: Int — The expected number of element move operations during copying.
  • move_moves: Int — The expected number of element move operations during moving.

Raises

AssertionError: If any copy, move, or delete count differs from the expected value.
