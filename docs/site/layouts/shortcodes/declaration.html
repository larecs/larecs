The readable form drops the `where (eq ...)` clauses that `mojo doc` emits for inferred parameters and shortens parameter types that only restate their own parameters, such as `filter: Filter[filter._include, ...]`. When this changes the text, the exact declaration follows in a collapsed block. */ -}} {{- /* The template wraps the declaration in a code fence so Modo leaves it unchanged. */ -}} {{- $exact := strings.TrimSpace .Inner -}} {{- $exact = replaceRE "^```mojo\n" "" $exact -}} {{- $exact = replaceRE "\n```$" "" $exact -}} {{- $readable := replaceRE `\s+where \(eq .*$` "" $exact -}} {{- $readable = replaceRE `: (\w+)\[[a-z_]\w*\.\w+[^\[\]]*\]` ": $1" $readable -}} {{- transform.Highlight $readable "mojo" -}} {{- if ne $readable $exact }}
